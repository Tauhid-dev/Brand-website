# Framework Roadmap

## v1 — Foundation (complete)

Deterministic generation, sixteen engines, templates, doctrines, agents, skills,
schemas, Mermaid/SVG diagrams, chunks, memory, ten validators, CLI, scripts, docs,
examples, tests, SemVer, and migrations policy.

## Next minor milestone — Profiles and richer validation

- Optional organisation and domain overlays without changing the three-field input.
- Full JSON Schema validation through an optional adapter.
- Optional official Mermaid CLI renderer and visual regression fixtures.
- Link/reference validation and configurable severity policies.
- Signed template-pack provenance and extension registry.

## v2 candidates

Evaluate only from evidence: formal plugin discovery, declarative pipeline profiles,
and bidirectional migration reports. No candidate is a commitment until an ADR defines
the public contract and migration.
