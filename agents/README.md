# Reusable Agent System

Agents are bounded roles, not autonomous authorities. Each contract declares mission,
inputs, outputs, responsibilities, constraints, and quality gates. An orchestrator may
select multiple roles, but ownership and final approval remain with named project people.

Every agent must read the constitution, active chunk, current state, and relevant skill
packs; distinguish facts from assumptions; remain within scope; protect sensitive data;
cite material sources; record evidence; and update durable memory before handoff.
