# Review a Project Foundation

Review the generated repository as an independent principal engineer. Validate the
manifest and all contracts. Trace outcomes → requirements → acceptance → architecture →
risks → tests → chunks → evidence. Look for hidden assumptions, premature technology,
dependency cycles, missing trust boundaries, unowned risks, unverifiable gates,
diagram drift, and resume gaps.

Report findings by severity with exact artifact, violated rule, impact, and a bounded
remediation. Do not modify files unless explicitly asked. If there are no findings,
state which validators and evidence were inspected.
