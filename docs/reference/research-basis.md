# Research Basis

The foundation adopts these stable primary references:

- [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html) for public contract
  compatibility and migrations.
- [JSON Schema Draft 2020-12](https://json-schema.org/draft/2020-12) for portable machine
  contracts.
- [NIST Secure Software Development Framework](https://csrc.nist.gov/projects/ssdf) for
  outcome-based secure development practices across prepare, protect, produce, and
  respond activities.
- [C4 model](https://c4model.com/) for hierarchical architecture communication and
  [C4 notation guidance](https://c4model.com/diagrams/notation) for explicit titles,
  element meaning, and labelled relationships.
- [Mermaid usage](https://mermaid.js.org/config/usage) for text-authoritative diagrams
  that can produce SVG views.

The framework deliberately separates stable concepts from tool choices. These sources
inform contracts and review rules; they do not create a dependency on a hosted service.
