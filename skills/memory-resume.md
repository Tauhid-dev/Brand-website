# Memory and Resume Skill

- **Purpose:** Preserve enough verified state to resume after months without chat context.
- **When to use:** Start/end of every session, decision, blocker, or chunk transition.
- **When NOT to use:** For secrets, raw logs, speculative transcripts, or duplicate volatile detail.
- **Inputs:** Current artifacts, decisions, evidence, risks, debt, chunk state.
- **Outputs:** Current state, handoff, summary, progress, machine cursor, one next action.
- **Dependencies:** Active chunk and version control evidence.
- **Example:** Record a blocked C003 with exact failed gate, evidence, decision owner, and resume command.
